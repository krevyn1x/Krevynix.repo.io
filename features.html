Referenced features

Message history, call recording, status archives, hidden chats, online activity, sticker editing, media vaults and cloud backup require separate implementations. They are not available in this release. The suite does not redistribute Watusi or change Adobe's server subscription state.

Bootstrap support

Rootful, rootless and RootHide use separate build schemes. Compatibility is reported per archive; a successful build is not a runtime test on every jailbreak.
